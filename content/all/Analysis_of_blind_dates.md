# 考虑因素

收入，独立婚房，学历，车，贷款/欠债，是否和父母住一起，父母兄弟姐妹情况，性格(包括控制欲、依赖度、过度自信)，疾病，性取向

# 哲学
1. 凡事多问为什么，多换位思考。在什么时间在什么情形下谁说的这句话？为什么要说这句话？为什么用的是这个词而不是其它类似意思的词？内心的纠结是怎样的？一个问题有多个可能的回答，不要钻牛角尖只考虑一个。
2. 之前的结论也可以作为进一步推理的条件。
1. 没写的就是希望隐瞒的，可能隐瞒的有：肥胖、负债、性格不好、同性恋、离异情况、是否有孩子。
2. 写了的缺点说明缺点问题极大
3. 门当户对原则，天上掉馅饼的事情，必有鬼
4. 上下进行关联推理，一个结论最好能得到多个证据的支持。一个谎言需要更多的谎言来找补，在确定是谎言的情况下，这种找补其实是可以看出来的。
5. 如果看出了矛盾点或者觉得小概率的事件，思考该现象出现的原因是什么。
8. 前面一路顺风顺水，突然就断了，什么原因？

# 经验
1. 身高是假的，男性会自动向 180 cm调整。
2. 年龄大说明被挑剩下或者离异，思考为什么；如果是非离异男性，多半是因为经济原因，还可能是性格原因或者同性恋。年龄大的人不会冲动行事，闪婚必有鬼。
3. 年纪小可能是被父母控制、身体或精神有问题
4. 主业收入不行就会提副业，主业好的不会提副业的。
5. 在条件里面谈到理财留个心眼，可能杀猪盘、欠债、侵吞你的钱财。
6. 提到公司、企业或创业。是不是负债或低收入？为什么具体的名字？为什么不谈流水？为什么不谈资产？
7. A9家庭大概率会父母离异大概率会再次结婚，因为需要人来打理家庭。
9. 单亲家庭跟母亲，则或者孩子依赖母亲，或者母亲依赖孩子(例如北大弑母案中的吴谢宇母子)。在家庭中，你才是来者。
10. 想快点要孩子、可闪婚：可能父母控制欲大、父母快死了、不看重夫妻感情、功利心重
11. 当兵的目的：谋发展、谋金钱、磨心性、爱国
12. 没有压力、喜欢做饭、没有写喜欢运动则大概率胖
13. 体制内的家庭传统观念重。

# 潜台词

1. 你要会过日子：会控制家庭开支、会省钱、会照顾人、会做家务、有工作
2. 我会过日子：我扣门
3. 孝顺：你要照顾我的父母
4. 比较闲、爱看书：爱胡思乱想，心思敏感
5. 勤劳：会做家务、会照顾人
6. 尊重我：给我发脾气的资格，自尊心强，好面子
7. 乐观、有生活态度：我生活很艰难

# 典型人物

典型人物意味着在人物光谱中处于一个极端的位置，在现实中也很少见，下面只是罗列一些**相关性内容**，并不是一定如此。

1. 佛系人生：“知足常乐”，看上去比实际年龄年轻，对未来规划少，容易胖。
2. 妈宝男：没有自己买的车房；有和妈妈的固聊（每日固定聊天），和妈妈住在一起，抗压能力差。
3. 控制狂：洁癖，喜欢恋爱脑，离异
4. 家族弃子：表面上看资产很多，学历甚至很低，不得宠，想要创业(家族企业中没有他的位置)
5. 凤凰男：在乎形象和面子，容易答应亲戚的要求；大男子主义；家庭观念强，愚孝愚忠；自负自卑自私，自身定位不清晰；金钱上斤斤计较
6. 销售员：接触的大佬多，以为自己也是大佬；油滑，看重关系，认为关系能解决一切问题。
7. 入赘男：家里还有哥哥或弟弟，并且在原生家庭不受宠，心理有问题，对冠姓有执念（为数不多的能够证明自己存在的机会）
8. 胖子：无法克制欲望
